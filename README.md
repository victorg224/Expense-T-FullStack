# 💰 Expense Tracker

A full-stack web application that allows users to track their spending by adding expenses with the date, item name, and price. Total spent updates dynamically as items are added or removed.

---

## ✅ Features
- Add expenses (date, item, price)
- Display all expenses in a table
- Remove expenses from the list
- Calculates and updates total spent
- Saves data in a PostgreSQL database

---

## 🛠 Tech Stack
- **Frontend:** React, Vite, JavaScript, CSS/Tailwind
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
